# Gulabi Glow — Luxe Lip Nectar E-Commerce Atelier

A modern South Asian luxury beauty storefront celebrating handcrafted botanical luster lip glosses.

## Features
- **4 Signature Shades**: Rooh Gulabi ($26.00), Sonehri Shaam ($26.00), Mithai Berry ($28.00), Noor Clear ($24.00)
- **Interactive Shopping Bag & Checkout**: Slide-out cart drawer, dynamic $45 free shipping threshold calculation, promo codes (`GLOW10`, `LUMINOUS15`), mock checkout with order receipt generation.
- **Search Boutique**: Real-time filtering modal across shades, finishes, and descriptions.
- **Multi-Currency Switcher**: Real-time conversion across USD ($), EUR (€), GBP (£), CAD ($), and INR (₹).
- **Atelier Concierge Desk**: Functional Contact Us form connected directly to Web3Forms API.
- **Interactive Features**: Product Quick View modal, Virtual Shade Matcher Quiz, and Inner Sanctuary newsletter subscription.

## Running Locally
Double-click `start_server.bat` or run:
```powershell
powershell -ExecutionPolicy Bypass -File ./server.ps1 -Port 8000
```
Open [http://localhost:8000/](http://localhost:8000/) in your browser.
